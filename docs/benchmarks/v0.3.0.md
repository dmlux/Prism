# v0.3.0 — reproducible benchmarks on the checked-in example texts

First measurement under the reproducible protocol introduced in 0.3.0:
every input is a checked-in CC0 text under `data/examples/`
(`skarvholmen-bokmaal.txt`, 55 sentences / 905 tokens;
`fjellvatnet-nynorsk.txt`, 41 sentences / 803 tokens), so anyone can
rerun the suite on their own hardware without files that exist on only
one machine. Earlier records
([prism-no-0.2.2.md](prism-no-0.2.2.md)) were measured on a private
book-chapter text; absolute numbers are therefore not directly
comparable across the protocol change.

Model quality is unchanged in this release (model `prism-no-0.2.2`;
frozen test-split results in [prism-no-0.2.2.md](prism-no-0.2.2.md)).
The example texts carry no gold annotation; their pinned quality
contract is exact cross-binding parity: identical sentence and token
counts, subword IDs, and byte-offset source ranges across the Python
reference, C++, Swift, and Java suites.

## Protocol

- Machine: Apple M4 Max (16-core), macOS 15, release builds, default
  thread policy.
- Model: `prism-no-0.2.2` (fp32) and `prism-no-0.2.2-fast` (int8).
- C++ suite: Google Benchmark v1.9.1 (vendored),
  `--benchmark_repetitions=3 --benchmark_report_aggregates_only=true`,
  median reported. Document-scale rows repeat the Bokmål text past
  6,000 tokens to match the documented document-inference protocol.

```bash
cmake -S cpp -B cpp/build -DCMAKE_BUILD_TYPE=Release -DPRISM_BENCHMARKS=ON
cmake --build cpp/build --target prism_benchmarks --parallel
cpp/build/prism_benchmarks --benchmark_repetitions=3 --benchmark_report_aggregates_only=true
```

## C++ results (median of 3)

| Benchmark | fp32 | fast (int8) |
| --- | ---: | ---: |
| Tagger load | 33.3 ms | 35.1 ms |
| TagText, document scale | 1,813 tokens/s | 3,543 tokens/s |
| Tag (pretokenized), document scale | 1,832 tokens/s | 3,590 tokens/s |

Model-independent stages (per text, single pass):

| Stage | Bokmål | Nynorsk |
| --- | ---: | ---: |
| Runtime segmentation | 8.0 M tokens/s | 8.6 M tokens/s |
| Byte-level BPE encode | 2.24 M tokens/s | 2.58 M tokens/s |

Segmentation and BPE together stay under half a millisecond per text —
end-to-end cost is the model forward pass; `TagText` versus
pretokenized input differs by about 1%.

## Swift cross-check (fast artifact, single Bokmål text)

`PRISM_ARTIFACT=models/prism-no-0.2.2-fast swift test -c release
--filter ChapterBenchmarkTests` — single pass over the 905-token text,
so batches are less saturated than in the document-scale C++ rows:

| Stage | Measurement |
| --- | ---: |
| Load artifact + program + tokenizer | 52 ms |
| Segmentation (55 sentences) | 0.6 ms |
| BPE (1,214 subwords) | 1.4 ms |
| tag(sentences) | 2,101 tokens/s |
| tagText warm | 387 ms (905 tokens) |
